# Brand and logo assets

Logo and silkscreen artwork used on the board and in documentation.

- `svg/` — vector logos (RAMMP, ATDev, PaceRacer, DuckSpark, RotoDuk). Import these into KiCad via the Image Converter for silkscreen.
- `png-1x/`, `png-128w/` — raster exports of the above.
- `rotoduck/` — RotoDuk logo rotation sweep (SVG + PNG).
- `src/` — Photoshop source files, stored via Git LFS.

These are not KiCad project files and will move to a shared brand-assets repo once one exists.
